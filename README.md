## 🛠️ Comandos de Despliegue en GitHub Pages

Para publicar esta landing page en GitHub Pages:

### 1. Inicializar el repositorio Git e incluir el commit inicial
```bash
git init
git add .
git commit -m "feat: inicializacion de landing page corporativa premium Punto Hogar S.A.S."
```

### 2. Vincular con su repositorio remoto en GitHub
```bash
git remote add origin https://github.com/SU_USUARIO/punto-hogar-landing.git
git branch -M main
git push -u origin main
```

### 3. Activar GitHub Pages en el Repositorio
1. Vaya a su repositorio en GitHub -> **Settings** -> **Pages**.
2. En **Source**, seleccione la rama `main` (o `gh-pages`) y la carpeta `/ (root)`.
3. Haga clic en **Save**.
4. Su sitio estará publicado automáticamente en `https://SU_USUARIO.github.io/punto-hogar-landing` o en su dominio personalizado `puntohogar.space`.
